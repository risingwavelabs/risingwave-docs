This page lists the Docker images published for each RisingWave Console release. The dates below are the dates when the primary versioned Docker image tags were last pushed, in UTC.

Release change summaries will be added when an authoritative release-note source is publicly available. For deployment requirements and configuration, see [Install RisingWave Console](/web-ui/risingwave-console/installation-setup). For details about the `airgap-*` images, see [Air-gapped deployment](/web-ui/risingwave-console/air-gapped-deployment).
