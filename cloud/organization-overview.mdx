## Concept

An organization owns its projects, database objects, network connections, users, and service accounts. Role-based access control determines which resources each user or service account can access. When you sign up for RisingWave Cloud, an organization is automatically created for you.

In an organization, you can:

* Grant organization-wide or project-scoped access to users and service accounts.
* Allow selected users and applications to manage project resources.
* Set up Single Sign-On (SSO).
* Set up service accounts for your applications that access RisingWave Cloud using API keys.
