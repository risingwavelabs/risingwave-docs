This alert indicates that compaction back pressure has been detected in your project.

## Common triggers

- Insufficient compaction resources.

## Diagnosis

- Check compaction CPU usage.
- Compare the CPU utilization of Streaming Nodes, Serving Nodes, and Compactor Nodes.

## Resolution

Scale out the Compactor Nodes. For more information, see [Scale a project manually](/cloud/scale-a-project-manually).
