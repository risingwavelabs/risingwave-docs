This alert indicates that data for a sink has remained pending in RisingWave's internal log store for longer than the configured threshold.

## Common triggers

- Slow processing in the downstream system.
- Insufficient sink parallelism.

## Diagnosis

Check the downstream system for connectivity, availability, or throughput problems that could prevent the sink from processing data normally.
