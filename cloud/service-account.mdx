On the other hand, a service account represents an application. It accesses RisingWave Cloud resources on the application's behalf, using API keys for authentication."

This article will guide you through the process of setting up a service account for your applications and generating an API key.

A service account has a system-managed `OrganizationMember` role and can have additional organization-wide or project-scoped role bindings. Its API keys use the service account's combined access. For details, see [Role-based access control](/cloud/organization-rbac).

## Create a service account

**Steps:**

1. Go to [**Organization**](https://cloud.risingwave.com/dashboard/organization) and select the **Service accounts** tab.
2. Click **New**.
<Frame>
  <img src="/images/cloud/service-account/org-create-service-account-v2.png"/>
</Frame>
3. Enter a descriptive name for your service account and write a short description.
4. Click **Confirm**.
<Frame>
  <img src="/images/cloud/service-account/org-service-account-v2.png"/>
</Frame>

The new service account does not have permission to operate project resources. To grant access, go to **Organization** \> **Access**, click **Add access**, select the service account as the **Principal**, and choose the required **Role**, **Scope**, and **Scope target**. For least privilege, use a project-scoped `ProjectAdmin` role when the application needs to operate only one project.

## Generate an API key

You can generate multiple API keys for a service account. Each API key has a unique key ID and secret and inherits the service account's effective permissions.

**Steps:**

1. In the account list, click the name of the service account you want to generate API keys for.
    <Frame>
      <img src="/images/cloud/service-account/org-service-account-1-v2.png"/>
    </Frame>

2. Select the **API Keys** tab.
    <Frame>
      <img src="/images/cloud/service-account/org-service-account-api-empty-v2.png"/>
    </Frame>
3. Click **Add new API Key**.
4. Enter a descriptive name for your API key and click **Submit**.
5. A new API key will be generated. Please save the secret along with the ID to a safe place.
    <Warning>
    The secret will be shown only once. After you close the dialog, you won't be able to retrieve it. If you lose the secret, you have to generate a new API key.
    </Warning>
    <Frame>
      <img src="/images/cloud/service-account/org-service-account-api-key-v2.png"/>
    </Frame>
