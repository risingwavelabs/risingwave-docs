## Check all clusters

To browse each cluster's configuration and running status in your account, go to the [RisingWave Cloud dashboard](https://cloud.risingwave.com/dashboard).

On the dashboard, you can see all clusters in your account and [control their running states](/cloud/stop-and-delete-projects/). You can also check the current plan, RisingWave version, region, and creation time of each cluster here.

## Check cluster details

To enter the cluster details page, go to the [RisingWave Cloud dashboard](https://cloud.risingwave.com/dashboard) and click the cluster you want to inspect.

The cluster details page includes:

* Current activities
* Current usage
* Configuration details
* Metrics
   * Key indicators — CPU usage, memory usage, throughput, storage usage, and network
   * Streaming — barrier latency, in-flight barrier number, backfilling throughput, backpressure rate
   * Query — query per second, query average latency
   * UDF — UDF call count, UDF latency, UDF throughput
* [PrivateLink](/cloud/privatelink-overview/)
* [Database users](/cloud/manage-database-users/)

<Tip>
To specify the time range of the metrics, go to the **Metrics** page, and click **Last 30 minutes** in the top right corner to customize your time range.
</Tip>
