---
title: "Monitor materialized views"
sidebarTitle: "Materialized views"
description: "You can view all [materialized views](/reference/key-concepts#materialized-views) defined in the databases of a cluster."
mode: wide
---

1. Go to the [RisingWave Cloud dashboard](https://cloud.risingwave.com/dashboard), and open the cluster that contains the materialized view.

2. In the cluster navigation, select **Data Catalog**. Choose the database and schema, then open the **Materialized Views** tab.

3. Click on a materialized view to see the details.
You can view the direct acyclic graph of streaming executors for maintaining the materialized view.

4. In the cluster navigation, click **SQL Editor** to see the query defined in the materialized view (i.e. the `AS` clause).
