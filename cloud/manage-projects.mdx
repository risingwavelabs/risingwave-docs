Clusters are listed on the RisingWave Cloud dashboard. From the dashboard, you can create clusters, open a cluster, pause or resume it, restart it, rescale it, upgrade it, and delete it.

## Create a cluster

To create a cluster in RisingWave Cloud, follow these steps:

1. Go to the [RisingWave Cloud dashboard](https://cloud.risingwave.com/dashboard).
2. Click **New cluster**.
3. Select the deployment mode, plan, cloud provider, region, and compute resources. For more details, refer to [Choose a cluster plan](/cloud/choose-a-project-plan/).
4. Review the summary and create the cluster.

Once the cluster is created, it appears on the dashboard. Open it to access its **Connect**, **Data Catalog**, **SQL Editor**, **Metrics**, **Resources**, **Users**, **Backup**, **Maintenance**, and **Network Access** pages.
