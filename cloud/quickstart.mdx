## Step 1: Create an account

You can use your company email to create an account.

1. [Sign up](https://cloud.risingwave.com/auth/signup/) for RisingWave Cloud.
2. [Log in](https://cloud.risingwave.com/auth/signin/) to your account.

Alternatively, continue with your third-party account: **Google**, **Microsoft**, or **Github**.

## Step 2: Create a cluster

After you sign up, open the [RisingWave Cloud dashboard](https://cloud.risingwave.com/dashboard) and click **New cluster**. A cluster in RisingWave Cloud provides the resources for hosting independent data repositories and streaming pipelines. Within a cluster, you can create and manage database users and databases.

You can choose a Basic cluster or a customizable Pro cluster if your organization has access. See [Choose a cluster plan](/cloud/choose-a-project-plan/) to decide on a plan and configure the resources.

## Step 3: Connect to your cluster

After getting a cluster up and running, connect to it so that you can interact with RisingWave.

Choose from the following ways to connect to your cluster.
<Tabs>
  <Tab title="SQL Editor">
The SQL Editor offers a notebook-style interface for writing SQL, running queries, viewing results, and creating quick visualizations.

#### To connect via SQL Editor, follow the steps below:

1. In RisingWave Cloud, go to the [dashboard](https://cloud.risingwave.com/dashboard), and open the cluster you want to use.
2. In the cluster navigation, click **SQL Editor**.
3. For detailed instructions, see [SQL Editor](/cloud/console-overview/).

  </Tab>
  <Tab title="Local client">
If you need to connect to the RisingWave cluster via local clients, you can configure the connection in multiple ways.

#### To connect with any local clients, follow the steps below:

1. In RisingWave Cloud, go to the [dashboard](https://cloud.risingwave.com/dashboard), and open the cluster you want to connect to.
2. In the cluster navigation, click **Connect**.
3. Select a database user, database, and connection format.
4. You may need to set up a CA certificate to enable SSL connections. See the instructions displayed on the portal for more details.
5. Copy the command and run it in a terminal window.
6. Log in with the password of the database user.

For detailed instructions, see [Local client](/cloud/connect-to-a-project/#local-client).
  </Tab>
</Tabs>

## Step 4: Explore RisingWave with examples

You can kickstart your journey with RisingWave by exploring templates and sample SQL in the cluster **SQL Editor**.

These demos cover the most common steps in using RisingWave, such as establishing a connection with a data source, processing data by defining materialized views, and querying the results.

## Step 5: Ingest, process, and deliver data
