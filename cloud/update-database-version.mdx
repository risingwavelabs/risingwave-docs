## What to expect during upgrade

Here’s what you should know about the upgrade:

**Before the upgrade starts**:

- RisingWave Cloud automatically backs up your data.

**During the upgrade process**:

- Cluster operations will be temporarily unavailable.

- Streaming pipelines will be halted and experience temporary downtime.

- Query Serving, being more lightweight, will typically recover faster than streaming pipelines.

- You won’t be charged for compute resources during this period.

## How to upgrade

### Upgrade in the Cloud portal

1. Go to the [RisingWave Cloud dashboard](https://cloud.risingwave.com/dashboard), and open the cluster you want to upgrade.
2. Click **Upgrade** in the cluster header or the upgrade banner on the **Overview** page.
3. Wait for the upgrade to complete. This typically takes a few minutes.

The Cloud portal upgrades your cluster one eligible release at a time. If a newer patch is available for the current minor version, the portal targets the latest supported patch first. Otherwise, it targets the latest supported patch of the next minor version. Repeat the steps above to move through multiple minor versions.

### Upgrade with Terraform

If you manage your cluster with the [RisingWave Cloud Terraform Provider](https://registry.terraform.io/providers/risingwavelabs/risingwavecloud/latest/docs), update the `version` attribute of the [`risingwavecloud_cluster` resource](https://registry.terraform.io/providers/risingwavelabs/risingwavecloud/latest/docs/resources/cluster#version), then run `terraform plan` and `terraform apply`.

We recommend upgrading one minor version at a time. Contact RisingWave Support before skipping a minor version, because some upgrade paths may require intermediate migration steps.

If the cluster was upgraded outside Terraform, such as through the Cloud portal or by RisingWave Support, update the `version` attribute in your Terraform configuration to match the cluster's current version before the next `terraform apply`. Otherwise, Terraform will attempt to restore the older configured version, and the apply will fail because downgrades are not supported.

<Note>
The `version` attribute belongs to the RisingWave Cloud Terraform Provider. The separate BYOC infrastructure Terraform module does not manage the RisingWave database version.
</Note>

<Note>
You can only upgrade to newer versions of RisingWave. Downgrading to previous versions is not supported.
</Note>
