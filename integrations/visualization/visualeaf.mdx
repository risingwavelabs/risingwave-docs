This guide shows how to connect [VisuaLeaf](https://visualeaf.com/database/risingwave/) to RisingWave so you can browse your tables and run SQL against RisingWave from a desktop client.

## Prerequisites

* Ensure that VisuaLeaf is installed. To download VisuaLeaf, see the [VisuaLeaf download page](https://visualeaf.com/download). A free Community Edition is available, along with paid editions.
* Install and start RisingWave. For instructions on how to get started, see the [Quick start guide](/get-started/quickstart).

## Establish the connection

1. In VisuaLeaf, click **New Connection**.
2. In the database picker, search for `risingwave` and select **RisingWave**. VisuaLeaf fills in the RisingWave defaults for you.
3. Provide the following information:
   * Host: The hostname or IP address of the RisingWave database. The default **Host** is `localhost`.
   * Port: The port number of the RisingWave database. The default **Port** is `4566`.
   * Database: The name of the RisingWave database you want to connect to. The default **Database** is `dev`.
   * Username: The username for accessing the database. The default **Username** is `root`.
   * Password: The password associated with the provided username. By default, there is no password for `root`.

    <Note>
    If you are connecting to RisingWave Cloud, use the host, port, database, username, and password from your cluster's connection details instead of the defaults.
    </Note>

4. Click **Test Connection**. If there are no errors, click **Save & Connect**.

Now that the connection is established, it is listed in the **Connections** sidebar. Expand it to see your databases and tables. By default, anything created in RisingWave will be listed under the `dev` database and the `public` schema. To run queries, right-click a database and select **New SQL Editor**, then click **Run All** (`F5`) or **Run** (`F9`). You can query tables and materialized views from the SQL editor, and view the results in a grid.
